## Лабораторная работа 1. 

Задача «Мастер прогулов 80-го уровня». Программа моделирует один семестр из 100 учебных дней. Каждый день у студента шесть пар: матанализ, линейная алгебра, дискретная математика, программирование, физика и английский язык.

За каждый прогул студент получает одно очко удовольствия. Ещё одно очко даёт пирожок в конце дня. Если на пропущенной паре студента спросили, он отчисляется и всё накопленное удовольствие обнуляется. Цель — набрать как можно больше очков за семестр.

В начале семестра каждому преподавателю случайно назначается одно из трёх правил:

1. Спросить с вероятностью 50%.
2. Спросить, если вчера спросили по предмету A.
3. Спросить, если вчера спросили ровно по одному из предметов A и Б.

Типы правил выбираются с равной вероятностью. Предметы A и Б также выбираются случайно и не совпадают друг с другом. В первый день считается, что вчера никого не спрашивали.

Студент не знает правил преподавателей. Стратегия реализует `ISkipStrategy` и один раз в начале дня возвращает решения по всем предметам: `true` — посетить, `false` — прогулять. История доступна через `IReadOnlyStudentHistory`: дни нумеруются с 1, после прогула и для ещё неизвестных результатов `WasAsked` возвращает `null`. Стратегия обновляет вероятности правил по доступным наблюдениям и учитывает риск потери очков. При неизвестных входах правила используется осторожная оценка риска опроса. Риск отчисления сохраняется.

В конце программа выводит результат семестра, общее удовольствие и среднее удовольствие за день. Среднее считается за полную настроенную длительность семестра, в том числе при отчислении.

## Запуск

Требуется .NET SDK 10. Команда из корневой папки проекта:

```powershell
dotnet run --project src/Lab01
```

Для повторения одного и того же семестра можно указать начальное значение генератора:

```powershell
dotnet run --project src/Lab01 -- --seed 42
```

Настройки находятся в `src/Lab01/appsettings.json`: `DayCount` — число дней, `SkipPleasure` и `PiePleasure` — очки за прогул и пирожок, `Seed` — начальное значение генератора (`null` для случайного выбора). По умолчанию семестр длится 100 дней, прогул и пирожок дают по одному очку. Параметр `--seed` имеет приоритет над файлом. При сборке файл копируется рядом с приложением.

## Лабораторная работа 2. Generic Host

Приложение работает непрерывно: каждые 5 секунд проходит новый учебный день. Первый день начинается через 5 секунд после запуска. После каждого дня выводятся накопленное удовольствие и среднее по прошедшим дням. На сотом дне программа не останавливается, история и очки продолжают накапливаться.

При отчислении удовольствие обнуляется и приложение завершается. Для ручной остановки можно нажать любую клавишу или `Ctrl+C`, в том числе во время ожидания следующего дня.

```powershell
dotnet run --project src/Lab02
```

Запуск с заданным начальным значением генератора:

```powershell
dotnet run --project src/Lab02 -- --seed 42
```

Общая логика обеих работ находится в библиотеке `SharpLabs.Core`. Во второй работе через DI подключены сервисы опросов преподавателей, истории, стратегии, расчёта дня, таймера, клавиатурного ввода и вывода результата. `SimulationWorker` выполняет дни, `KeyboardStopService` обрабатывает нажатие клавиши. Остановка происходит через `IHostApplicationLifetime` с отменой ожиданий.

Настройки второй работы находятся в `src/Lab02/appsettings.json`, в разделе `Simulation`. `DayIntervalSeconds` задаёт интервал между днями, `PlanningDays` — горизонт оценки риска стратегии, а не ограничение длительности программы. Здесь же задаются награды, `Seed` и период проверки клавиатуры. Параметры можно переопределить через командную строку, например `--Simulation:DayIntervalSeconds 1`, или переменные окружения, например `Simulation__Seed`.

Проверка решения:

```powershell
dotnet build SharpLabs.sln --configuration Release
dotnet run --project tests/Lab01.Tests --configuration Release
dotnet run --project tests/Lab02.Tests --configuration Release
```

## Лабораторная работа 3. Unit-тесты

Тесты на NUnit проверяют правила преподавателей, решения стратегии по истории опросов и поведение эмулятора при посещении, прогуле и отчислении. Все случайные значения в тестах заданы заранее.

Запуск из корня репозитория:

```powershell
dotnet test tests/Lab03.Tests/Lab03.Tests.csproj
```
